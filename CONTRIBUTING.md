# Contributing to radiom

Thanks for your interest in radiom!

## Pull requests are not accepted

radiom is a **solo-authored project**. It is open-sourced so others can
read the code and fork it for their own use, but the codebase stays
solo-authored — **pull requests will be automatically closed** (see
[`.github/workflows/no-prs.yml`](.github/workflows/no-prs.yml)).

## What is very welcome

- **[Issues](https://github.com/thepacket/radiom/issues)** — bug
  reports, decoder problems, build failures, feature requests. On-air
  results (what worked, what didn't, on which receiver/band) are
  especially useful.
- **[Discussions](https://github.com/thepacket/radiom/discussions)** —
  open questions, "how do I…", ideas you want to talk through before
  opening an issue.
- **Security reports** — please use GitHub's private
  [security advisories](https://github.com/thepacket/radiom/security/advisories/new)
  rather than a public issue.
